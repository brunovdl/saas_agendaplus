# 🎨 StitchMCP (Design System e Telas)

O **StitchMCP** é o assistente de design usado para criar e modificar interfaces visuais de alta fidelidade para o **Agenda+ SaaS**.

## 📐 Diretrizes Visuais (Martins AI Automation)
* **Mobile-First**: Componentes estruturados prioritariamente para visualização mobile (`< md` com barra de navegação base).
* **Estilo Premium**: Estética moderna com gradientes suaves, tipografias robustas (Inter/Outfit) e transições fluidas.
* **Componentização**: Criação de componentes React reutilizáveis que seguem os padrões definidos em `tailwind.config.js`.
